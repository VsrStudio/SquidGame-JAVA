# SquidGame Plugin

## Description
SquidGame plugin for PaperMC servers that allows players to play mini-games based on the **Squid Game** show. Players will go through different stages and can earn rewards at the end.

## Features
- Red Light, Green Light
- Tug of War
- Glass Bridge
- Rewards for the Winners
- Join and Leave Game Menu
- Spectator Mode

## Installation
1. Place the plugin in the `plugins/` folder of your PaperMC server.
2. Make sure Vault plugin is installed if you're using an economy system.
3. Run the server.

## Commands
- `/join` - Join the game.
- `/leave` - Leave the game.
- `/start` - Start the game (Admin only).

## Configuration
- You can configure arena locations, rewards, and other settings in the `config.yml` file.

## Usage
- **Join the Game**: Use the `/join` command to enter the game.
- **Leave the Game**: Use the `/leave` command to exit the game.
- **Start the Game**: Admin can use the `/start` command to begin the game.

## Notes
- This plugin relies on a stage-based game system.
- Make sure players follow the rules to avoid elimination.
- The game progresses automatically after each stage, with players being eliminated if they fail the challenges.
