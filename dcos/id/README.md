# Plugin SquidGame

## Deskripsi
Plugin SquidGame untuk server PaperMC yang memungkinkan pemain untuk bermain mini-game berdasarkan acara **Squid Game**. Pemain akan melewati berbagai tahapan dan bisa mendapatkan hadiah di akhir permainan.

## Fitur
- Lampu Merah, Lampu Hijau
- Tarik Tambang
- Jembatan Kaca
- Penghargaan untuk Pemenang
- Menu Bergabung dan Keluar dari Permainan
- Sistem Spectator

## Instalasi
1. Tempatkan plugin di folder `plugins/` server PaperMC Anda.
2. Pastikan Vault plugin sudah terpasang jika menggunakan sistem ekonomi.
3. Jalankan server.

## Komando
- `/join` - Bergabung ke permainan.
- `/leave` - Keluar dari permainan.
- `/start` - Mulai permainan (Admin).

## Konfigurasi
- Anda dapat mengonfigurasi arena, hadiah, dan pengaturan lainnya di file `config.yml`.

## Penggunaan
- **Bergabung ke Permainan**: Gunakan perintah `/join` untuk masuk ke permainan.
- **Keluar dari Permainan**: Gunakan perintah `/leave` untuk keluar dari permainan.
- **Mulai Permainan**: Admin dapat menggunakan perintah `/start` untuk memulai permainan.

## Catatan
- Plugin ini bergantung pada sistem permainan berbasis tahapan.
- Pastikan pemain mengikuti aturan yang ada untuk menghindari eliminasi.
- Permainan akan dilanjutkan otomatis setelah setiap tahap, dengan pemain yang gagal akan dieliminasi.
